# 프로젝트 지침

이 파일은 하네스가 아니라 이 레포가 직접 관리하는 규칙입니다.
스킬과 에이전트는 이 문서에 적힌 규칙을 기본 규칙보다 먼저 따릅니다.

## 먼저 할 일

프로젝트를 시작할 때 아래 "커밋 규칙", "브랜치 규칙", "PR 규칙"의 빈칸을 직접 채웁니다.
채워 두면 에이전트는 그대로 따릅니다.

## 규칙이 비어 있을 때 (에이전트에게)

커밋, 브랜치, PR 규칙 칸이 비어 있으면 형식을 임의로 정하지 않는다.

- 사용자가 처음 만든 커밋 메시지(또는 PR 제목)의 형식을 이 프로젝트의 규칙으로 삼는다.
- 형식을 정리해서 사용자에게 보여 주고, 확인받은 뒤에 이 문서의 빈칸에 적는다.
- 아직 커밋이 없으면 첫 커밋 메시지는 사용자에게 정해 달라고 하거나, 제안해서 사용자가 고치게 한다. 혼자 정하지 않는다.
- 이미 채워진 칸은 사용자가 바꾸라고 하기 전에는 고치지 않는다.
- PR 본문은 `.github/PULL_REQUEST_TEMPLATE.md`가 있으면 그것을 따른다. 없으면 제목 형식만 기록한다.
