# skills

Claude Code가 정해진 절차로 일할 때 쓰는 스킬 모음입니다. 스택과 컨벤션에 상관없는 작업 방식만 담았고, 프로젝트별 규칙(테스트 명령, 저장 위치 등)은 각 레포의 `CLAUDE.md`에서 가져옵니다.

## 목록

| 스킬 | 하는 일 | 파일 수정 |
|---|---|---|
| `spec-interview` | 구현 전에 인터뷰로 요구사항과 제약을 정리해 스펙 문서 작성 | 스펙 문서만 |
| `root-cause-debugging` | 원인을 확인한 뒤에만 고치는 디버깅 절차 | 함 |
| `security-check` | 변경한 코드를 스택과 무관한 기준으로 보안 점검 | 안 함 |
| `test-writer` | 변경한 동작에 맞는 테스트를 작성하고 실행해 확인 | 함 |

커밋과 PR 스킬은 형식이 곧 컨벤션이라 넣지 않았습니다. 쓰는 사람이 자기 규칙에 맞게 추가합니다.

## 쓰는 방법

폴더째 쓰려는 레포의 `.claude/skills/`로 복사합니다. `install.sh`를 쓰면 한꺼번에 들어갑니다. 에이전트가 알맞은 때에 쓰기도 하고, 이름을 불러서 시킬 수도 있습니다.

## 스킬 추가

`core/skills/<이름>/SKILL.md`를 만들고 아래 프론트매터를 채웁니다. 참고 자료나 스크립트가 필요하면 같은 폴더에 둡니다.

```markdown
---
name: <폴더 이름과 같게>
description: <언제 쓰는지. 사용자가 할 법한 요청 문구를 넣는다>
allowed-tools: <필요한 도구만>
---

본문: 목적, 절차, 지킬 것, 보고 형식
```

특정 스택에만 해당하는 스킬은 `core/`가 아니라 `stacks/<이름>/skills/`에 둡니다.
