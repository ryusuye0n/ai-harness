# ai-harness

AI 코딩 도구에서 쓰는 스킬, 훅, 에이전트를 모아 둔 하네스입니다.

## 원칙

- **하네스는 도구만 제공합니다.** 스킬, 훅, 에이전트가 여기에 들어 있습니다.
- **컨벤션과 기술 스택은 쓰는 사람이 주입합니다.** 커밋 규칙, 브랜치 규칙, 코드 스타일 같은 프로젝트 지침은 하네스에 넣지 않고 각 레포의 `CLAUDE.md`에 직접 적습니다.
- **원본은 한 곳에만 둡니다.** `core/`와 `stacks/`가 원본이고, 도구별 파일은 `adapters/`가 원본에서 만들어 냅니다.

## 구조

```
ai-harness/
├─ core/            스택과 무관한 것
│   ├─ skills/      스킬
│   ├─ agents/      에이전트
│   └─ hooks/       훅 디스패처와 안전 모듈
├─ stacks/          스택별 묶음 (폴더 하나가 스택 하나)
├─ adapters/        도구별 변환 규칙
│   ├─ claude/
│   ├─ codex/
│   └─ gemini/
└─ templates/       레포에 복사해서 채워 쓰는 양식
    └─ CLAUDE.md
```

## 사용 방법

아직 설치 스크립트는 없습니다. 지금은 필요한 폴더를 쓰려는 레포의 `.claude/`로 직접 복사합니다.

1. `core/`의 필요한 스킬, 에이전트, 훅을 복사합니다.
2. 쓰는 스택이 `stacks/`에 있으면 그 폴더를 같이 복사합니다.
3. `templates/CLAUDE.md`를 레포 루트에 복사해서 프로젝트 규칙을 채웁니다.
